# Agent Rules For Flashcards Project

## Non-Negotiable Safety Tenet

All generated and curated content in this project must be soft, gentle, calm, and toddler-friendly.

- Images must avoid scary, violent, dark, or sharp visual themes.
- Audio must use warm, patient, toddler-safe tone and pacing.
- Words and translations must remain age-appropriate and simple.
- If a prompt or output conflicts with this tenet, reject or regenerate it.

This rule applies to UI copy, prompt templates, fallback assets, API integrations, tests, and future changes.
